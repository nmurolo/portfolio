## The brief

This self-initiated experiment explored how a simple catalogue could become a space for curiosity. Each object needed to feel distinct while remaining part of a coherent collection.

## The approach

I built a lightweight motion language from scale, rotation, and responsive type. The interactions adapt to pointer and touch input, with a reduced-motion version that keeps the experience equally useful.

## The outcome

The project became a reusable playground for testing interaction ideas. This third sample can be removed, reordered, or replaced by adding another Markdown file to this folder.
